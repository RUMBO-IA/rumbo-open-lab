# Support

Use the channel that matches the request.

- **Questions, usage ideas, and general community discussion:** GitHub Discussions.
- **Reproducible bugs in Open Lab material:** GitHub Issues.
- **Proposed code changes:** fork-first pull request after reading CONTRIBUTING.md.
- **Security-sensitive findings:** use GitHub private vulnerability reporting / Security Advisory flow as described in SECURITY.md.
- **Private RUMBO Core, production, customer systems, billing, employment, commercial support, or access requests:** this repository is not an authority channel for those systems.

Participation in Open Lab does not imply paid support, employment, organization membership, access to private repositories, deployment authority, or production support obligations.

Default cost posture: `EXTERNAL_SPEND_USD=0`.
